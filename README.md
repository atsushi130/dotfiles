# Dotfiles (2026年版)

Modern development environment configuration for macOS.

## Features

- **Shell**: Zsh with modern tools (starship, zoxide, direnv)
- **Editor**: Vim/Neovim with LSP support (coc.nvim)
- **Terminal**: iTerm2 / Warp
- **Browser**: Arc / Chrome
- **Version managers**: anyenv, rbenv, pyenv, nodenv, swiftenv
- **Modern CLI tools**: ripgrep, bat, exa, fd, fzf, gh

## Installation

```bash
git clone git@github.com:atsushi130/dotfiles.git
cd dotfiles
./install.sh
```

## Modern Tools Included

### Shell & CLI
- `starship` - Modern cross-shell prompt
- `zoxide` - Smarter cd command
- `direnv` - Environment variable management
- `gh` - GitHub CLI (replaces hub)
- `ripgrep` - Fast search (rg)
- `bat` - Better cat with syntax highlighting
- `exa` - Modern ls replacement
- `fd` - Better find
- `fzf` - Fuzzy finder

### Development
- `neovim` - Modern vim
- `git-delta` - Better git diffs
- `coc.nvim` - LSP-based completion
- `ale` - Asynchronous linting

## Requirements

- macOS
- Homebrew
- Git
